# CMP2003-Rating-Prediction
This was done as a group project for CMP2003 Data Structures and Algorithms class at BAU with the contributions of my friends Alp Emre, Emir Mert and Tutku.

The main goal of this project is to predict the ratings for a given movie by a given user by using previous ratings given by all the users to the movies. We do this by using neighborhood based collaborative filtering (NBCF), mainly user-based (UBCF) and item-based (IBCF).
A detailed explanation for these methods can be found in the PDF file.
